# 墨枢

Windows 桌面小说写作工具。AI 用你自己的 DeepSeek 密钥，所有作品只存在你的电脑上。

## 能做什么

- **写作**：章节目录、可换字体（可导入本地字体文件）、字号行距纸色、首行缩进、专注模式。AI 写的字浅黄底，改过之后只留虚线，状态栏显示本章 AI 占比。扫描“AI 腔”套话。选中文字可以让 AI 改写、扩写、缩写、换说法。
- **大纲页**：人物（简单版 / 12 组 82 项的详细版，人设随剧情变化、知情范围、称呼表）、大纲（卷、章、场景，可拖动）、事件时间线、篇幅规划。三者可以互相同步，执行前先预览，只执行勾选的项。
- **风格**：核心 / 次级 / 点缀三层组合，次级和点缀不限数量。风格块只写“怎么写”，不带人物和情节。
- **记忆**：四层记忆（近期、中期、早期、归档），每天定时结账：脚本班备份、结算、升降层；模型班写章节摘要、记人设变化、写日记、整理常驻页和作品圣经。漏跑会在下次打开时补上。
- **右下角 AI 助手**（Ctrl+J）：能读到整本书的人物、大纲、时间线、伏笔、记忆和正文，可以找思路、查设定、检查矛盾、推演假设。默认只聊天，不改作品；回复可以一键存为场景、加入时间线或记进记忆。
- AI 的每次修改都记在「记忆 → AI 变更记录」里，可以整组撤销。
- **不丢稿**：停笔 0.7 秒自动保存，状态栏显示「已保存 / 保存中 / 保存失败」，失败时先存本机草稿并自动重试。每章有「历史」：写满 10 分钟、字数变化 500 字、AI 改正文前、离开本章时自动留快照，可以对比差异、整章恢复。一章字数突然少了一半以上会先留快照再保存。删掉的书、章、场景进回收站，30 天内可恢复。只允许开一个墨枢窗口。
- **导入导出**：TXT 按「第X卷」「第X章」切章成书；按章节范围导出 Word / TXT / Markdown；「复制发文格式」一键贴到作者后台；作品包（.moshu.json）用来换电脑。
- **禁用清单**（风格页）：词、套路、剧情走向，所有 AI 任务都不许写，短词会在「扫描 AI 腔」里标出。写作页的「一致性检查」同时查人物、设定、时间线、前文和伏笔。

## 安装

到 [Releases](https://github.com/xiaomo1231/Outline-Management/releases/latest) 下载最新版：

- **安装版**：`moshu_x.y.z_x64-setup.exe`，双击安装。
- **免安装版**：`moshu_x.y.z_x64-portable.zip`，解压后双击 `墨枢.exe` 直接运行。

需要 Windows 10/11（自带 WebView2 运行库）。

第一次打开后到「设置」里填 DeepSeek API 密钥，点「测试连接并获取模型」。密钥存在 Windows 凭据管理器里，不进数据库。

数据在 `%APPDATA%\app.moshu.writer\` 下，数据库是 `moshu.db`，备份在 `backups` 文件夹：每天结账、关窗、写作时每 2 小时各备份一次，最近 24 份全留，另外 14 天里每天留一份。「设置 → 备份与恢复」可以整库恢复、从某份备份里取回单章，也可以设一个第二备份目录（例如网盘同步文件夹）。不要把 `moshu.db` 本身放进网盘同步，换电脑请用作品包。

## 更新到新版本

**v0.2.2 及以后**：到「设置 → 版本」点「检查更新」。有新版时墨枢会自己下载并核对校验值，下好后点「安装并重启」。安装前会自动保存正文、备份一份数据库，装好后自动重新打开。

**更早的版本**需要手动更新一次：

1. 打开 [Releases](https://github.com/xiaomo1231/Outline-Management/releases/latest) 下载新版。
2. 关掉正在运行的墨枢。保险起见，可以先到「设置 → 备份与恢复」点「立即备份」。
3. **安装版**：运行新的 `setup.exe`，覆盖安装到原来的位置。**免安装版**：用新的 `墨枢.exe` 替换旧的。
4. 打开墨枢，到「设置 → 版本」确认版本号已经变了。

作品数据在 `%APPDATA%\app.moshu.writer\`，安装版和免安装版共用，更新不会动它。新版第一次打开时会自动升级数据库，不用做任何事。墨枢不会自己联网检查更新，只有点「检查更新」时才访问 GitHub。

## 开发

需要 Node 20+ 和 Rust（stable）。

发布新版本：在 GitHub 的 **Actions → 构建 Windows 安装包 → Run workflow** 里填版本号（例如 `v0.3.0`）和可选的更新说明，或者直接推一个 `v0.3.0` 标签。构建会把版本号写进程序，并把安装版和免安装版发到 Releases，发布页自动附上这一版合并的 PR。

```bash
npm install
npm run dev          # 只开网页版调试，数据存在浏览器里
npm run tauri dev    # 开桌面版
npm test             # 单元测试
npm run tauri build  # 打包安装程序
```

代码结构：

- `src/lib/` 数据层（SQLite / 浏览器里用 sql.js）、大纲同步、篇幅规划、记忆、风格
- `src/lib/ai/` DeepSeek 接口、上下文组装、各项 AI 任务、每日结账
- `src/pages/` 各页面，`src/components/` 编辑器标记、风格搭建器、AI 助手
- `src-tauri/` 桌面壳（密钥存储、插件权限）
