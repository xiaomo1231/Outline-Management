# 墨枢

Windows 桌面小说写作工具。AI 用你自己的 DeepSeek 密钥，所有作品只存在你的电脑上。

## 能做什么

- **写作**：章节目录、可换字体（可导入本地字体文件）、字号行距纸色、首行缩进、专注模式。AI 写的字浅黄底，改过之后只留虚线，状态栏显示本章 AI 占比。扫描“AI 腔”套话。选中文字可以让 AI 改写、扩写、缩写、换说法。
- **大纲页**：人物（简单版 / 12 组 82 项的详细版，人设随剧情变化、知情范围、称呼表）、大纲（卷、章、场景，可拖动）、事件时间线、篇幅规划。三者可以互相同步，执行前先预览，只执行勾选的项。
- **风格**：核心 / 次级 / 点缀三层组合，次级和点缀不限数量。风格块只写“怎么写”，不带人物和情节。
- **记忆**：四层记忆（近期、中期、早期、归档），每天定时结账：脚本班备份、结算、升降层；模型班写章节摘要、记人设变化、写日记、整理常驻页和作品圣经。漏跑会在下次打开时补上。
- **右下角 AI 助手**（Ctrl+J）：能读到整本书的人物、大纲、时间线、伏笔、记忆和正文，可以找思路、查设定、检查矛盾、推演假设。默认只聊天，不改作品；回复可以一键存为场景、加入时间线或记进记忆。
- AI 的每次修改都记在「记忆 → AI 变更记录」里，可以整组撤销。

## 安装

在 GitHub 仓库的 **Actions → 构建 Windows 安装包** 里打开最近一次成功的运行，下载 `moshu-windows-setup`，解压后运行里面的 `墨枢_x.y.z_x64-setup.exe`。

第一次打开后到「设置」里填 DeepSeek API 密钥，点「测试连接并获取模型」。密钥存在 Windows 凭据管理器里，不进数据库。

数据在 `%APPDATA%\app.moshu.writer\` 下，数据库是 `moshu.db`，备份在 `backups` 文件夹，保留 14 份。

## 开发

需要 Node 20+ 和 Rust（stable）。

```bash
npm install
npm run dev          # 只开网页版调试，数据存在浏览器里
npm run tauri dev    # 开桌面版
npm test             # 单元测试
npm run tauri build  # 打包安装程序
```

代码结构：

- `src/lib/` 数据层（SQLite / 浏览器里用 sql.js）、大纲同步、篇幅规划、记忆、风格
- `src/lib/ai/` DeepSeek 接口、上下文组装、各项 AI 任务、每日结账
- `src/pages/` 各页面，`src/components/` 编辑器标记、风格搭建器、AI 助手
- `src-tauri/` 桌面壳（密钥存储、插件权限）
